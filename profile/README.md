## 🧠 Overview

Aseprite is a pixel art editor designed specifically for creating and animating sprites for games and retro-style graphics. It provides frame-by-frame animation tools, layers, and drawing utilities optimized for low-resolution artwork.

On a Windows machine it runs as a desktop application with its own workspace, settings folder and uninstall entry. Typical use is pixel art editor work on local files, so the application does not need a subscription or a cloud project to open and save documents.

## 🚀 Key Features

| Feature | Description |
| --- | --- |
| 🎨 Indexed color mode | Work with palette-based color systems, create and edit custom palettes with up to 256 colors for authentic retro graphics. |
| 🎬 Timeline animation | Build frame-by-frame animations with onion skinning, adjustable frame duration, and real-time preview of sprite motion. |
| 📐 Pixel-perfect drawing | Use specialized brushes and tools that respect pixel boundaries, including line and shape tools snapped to pixel grid. |
| 📚 Layer management | Organize artwork with multiple layers supporting different blend modes, opacity control, and group hierarchies for complex compositions. |
| 🔄 Symmetry drawing | Enable horizontal, vertical, or radial symmetry guides to automatically mirror brush strokes while drawing characters and objects. |
| ✂️ Spritesheet export | Generate optimized spritesheets with customizable layouts, trimming, and JSON metadata for game engine integration. |
| 🔲 Tilemap support | Create and edit tile-based maps directly within the editor, with tileset management and automatic tile placement tools. |
| 🖼️ Multiple file formats | Import and export PNG, GIF, BMP, and native ASE format with full animation and layer data preservation. |
| ⚡ Tag-based animation | Organize animation sequences into named tags for walk cycles, attacks, and idle states with independent playback ranges. |
| 🎭 Cel opacity and effects | Apply per-frame transparency and effects to individual cels without affecting the base layer structure or other frames. |
